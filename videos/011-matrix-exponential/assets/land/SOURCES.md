# Land data

- `raw/ne_110m_land.geojson`: Natural Earth 1:110m physical land polygons (public domain, naturalearthdata.com),
  fetched from https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson
- `land_pts.npy`, `ocean_pts.npy`: baked by `make_land.py` (Fibonacci sphere, 26,000 points, land mask).
